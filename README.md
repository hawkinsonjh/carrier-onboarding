# Hawkinson Freight LLC — Carrier Onboarding Packet

Official fillable carrier packet for Hawkinson Freight LLC (USDOT 9527567 · MC-58125397).

## Public link (turn on GitHub Pages first)

1. Open https://github.com/hawkinsonjh/carrier-onboarding/settings/pages
2. Source: **Deploy from a branch**
3. Branch: **main** / **/ (root)** → Save
4. Packet URL: **https://hawkinsonjh.github.io/carrier-onboarding/**

Put that URL on hawkinsonfreight.com (Carriers → Partner with us) and text/email it to carriers.

## What the packet collects

- MC / USDOT / legal name (with FMCSA SAFER lookup)
- Authorized rep, dispatch, after-hours, billing, claims
- Equipment, trucks, tracking, lanes
- Insurance limits, expirations, producer
- W-9 / TIN, remit, ACH or factoring
- Uploads: W-9, COI, authority, NOA / voided check
- Broker-carrier agreement + drawn e-signature

Submissions email **joe@hawkinsonfreight.com**. The first FormSubmit delivery requires a one-time confirmation click in that inbox.
